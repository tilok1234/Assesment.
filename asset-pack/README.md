# 8-bit Sprite Asset Pack

This directory is the locked pre-Cast/Death 12-column fixture baseline. It is
retained for regression compatibility and must not be regenerated merely to
match the current public 20-column runtime/export contract (`480x96` native,
`1920x384` at 4x). All committed fixture sheets share the historical layout
below and use a transparent background with no baked shadow.

- Frame size: 24x24 px, exported at 4x (96x96 px per frame)
- Sheet size: 1152x384 px (12 columns x 4 rows)
- Rows (top to bottom): down, left, right, up
- Columns (left to right): idle x2, walk x4, attack x4, hurt x2
- Suggested frame timings: idle 420ms, walk 150ms, attack 115ms, hurt 140ms

## Contents
- enemies/ - every enemy family & variant (202 sheets across 57 families)
- effects/ - 24 transparent, modular combat overlays across trails, projectiles, impacts, and statuses; no character/equipment occlusion is baked into these sheets
- players/ - 6 sample hero builds (make unlimited custom ones in the assembler)

Generated by the historical 12-column Sprite Assembler. The current
`sprite-engine.js` `buildSheet(spec, scale)` path emits the 20-column contract;
`npm run check` deliberately validates these 232 older fixture files without
rewriting them.

Re-audited on 2026-08-09: the locked pack still contains exactly 202 Enemy
fixtures and 232 PNG fixtures overall. The live assembler now exposes 80 Enemy
families / 259 variants, but that does not expand this historical fixture pack.
In particular, `enemies/zombie-ghoul.png` intentionally remains the legacy
Ghoul while the public runtime routes `zombie/ghoul` to the approved upgrade;
fixture regeneration requires a separate explicit approval.
